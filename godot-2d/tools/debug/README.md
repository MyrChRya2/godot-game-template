# tools/debug/ — 玩法调试件（本作专属）

这里放**只服务于本作**的调试工具：曲线预览、游戏内调参面板、状态可视化等。

## 为什么单独一个目录

**发布前要整体删掉它。** 分开之后，"删掉调试工具"就是一个可执行的动作（删这一个目录），
而不是"在一堆脚本里挑哪个是调试的"。

与 `tools/engine/` 的区别：

| 目录 | 性质 | 发布时 |
|---|---|---|
| `tools/engine/` | 改工程配置的脚本（主场景、渲染器、像素地基、输入动作）——**跨项目可复用** | **保留** |
| `tools/debug/` | 本作的玩法调试件（依赖本作的资源与场景） | **整个删除** |

> 详细说明见 `docs/PROJECT_TREE_TEMPLATE.md` §2.6。
